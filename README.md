 Week 05 — Security Fundamentals 

This week focuses on the core security concepts that are important for a SOC Analyst.

The main goal is to understand common cybersecurity threats and attacks, understand attacker behavior using MITRE ATT&CK.


 Objectives
By the end of Week 5, I aim to understand:

- CIA Triad
- Threat, Vulnerability, and Risk
- Common Cyber Attacks
- Web Application Attacks
- MITRE ATT&CK basics
- How SOC Analysts detect and investigate suspicious activity
